### "[bh_stress.sh](./bh_stress.sh)" - создание дополнительной нагрузки на основные ресурсы РС при тестировании СЗИ "Блокхост-Сеть".

---

Скрипт создает дополнительную нагрузку на основные железные ресурсы РС - CPU, Mem, IO. Создан для тестирования проивзодительности СЗИ "Блокхост-Сеть"

Скрипт был подготовлен для работы в **"РЕД ОС"** версий 7.3, 8.0.
