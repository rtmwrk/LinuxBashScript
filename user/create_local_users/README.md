### "[create_local_users.sh](./create_local_users.sh)" - пакетное создание локальных пользователей.

---

Скрипт создает заданное количество тестовых локальных пользователей. При создании новые локальные пользователи не будут иметь домашних каталогов.
Скрипт был подготовлен для работы в **Альт Линукс** версии 10, **"РЕД ОС"** версий 7.3, 8.0.
